About this tool

Chinese Class Notes Delivery is a tool used on the organizer’s own PC to support a small Chinese-language group class.

It sends study notes prepared from class whiteboard material and recordings to students using the organizer’s Gmail account. Recordings and note files are uploaded to the organizer’s own Google Drive and shared only with the relevant students.

This is a noncommercial tool for class participants, not a service offered to the general public. This website provides public information about the app and its policies.
